# نظام حياتي — My System Life

تطبيق أندرويد شخصي احترافي للروحانيات والتعافي، يعمل أونلاين/أوفلاين بنظام ١٢ ساعة.

> **تطوير: عبدالحميد الفرا**
> صدقة جارية عن روح الشهيد البطل **زهير الفرا** — بطل الدفاع المدني الذي
> استشهد في مجزرة المسعفين بتاريخ ٢٣ مارس ٢٠٢٥. اللهم تقبّله في الشهداء.

## المزايا
- 🏠 **اليوم**: نظرة شاملة على يومك.
- 🛡️ **التعافي**: نظام علمي للتعافي من الإباحية (عدّاد مزدوج، مراحل الدماغ، بروتوكول إنقاذ).
- 📿 **الأذكار**: تسبيح متعدد مع الفضائل، إدخال بالجملة، وحصيلة يومية/أسبوعية/شهرية/كلية.
- 📖 **البقرة**: تتبّع تلاوة سورة البقرة يومياً.
- 🕌 **الصلاة**: مواقيت من Aladhan API + كاش أوفلاين + إشعارات أذان.
- 📊 **الإحصائيات**: مخططات خطية بأطر زمنية متعددة.
- ⚙️ **الإعدادات**: تنسيقات، نسخ احتياطي، وعن التطبيق.

## التقنيات
Kotlin · Jetpack Compose · Material 3 · Hilt · Room · Retrofit · WorkManager · Vico

## البناء
- محلياً: افتح المشروع في **Android Studio** ثم Run.
- تلقائياً: عند الدفع إلى GitHub، يبني **GitHub Actions** ملف APK تجده في
  تبويب *Actions → آخر تشغيل → Artifacts*.

التصميم موثّق في [`DESIGN.md`](DESIGN.md).
